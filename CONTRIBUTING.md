# Contributing to Capbase

Thanks for helping. There are two ways to contribute, and they are licensed differently.

## Data

Add or correct companies, rounds, people and investors on [capbase.fyi](https://capbase.fyi).
Data submissions are governed by the [Terms of Service](https://capbase.fyi/terms): you grant
Capbase a broad licence to what you submit, and you must not submit anything copied from a
database whose terms forbid sharing it (for example, an export from a paid deal database).
Please attach a source URL wherever you can.

## Code

Capbase's code is licensed under the [GNU Affero General Public License v3.0](LICENSE). By
opening a pull request you agree that your contribution is licensed under the same terms
(AGPL-3.0-only), and that you have the right to submit it.

Before opening a pull request:

- read `CLAUDE.md` for the architecture and the design-system rules;
- run `yarn lint` (warnings fail the run) and `yarn test`;
- keep each pull request to one change, and explain the *why* in the description.
